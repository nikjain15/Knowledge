# Lakewell Knowledge

A working prototype of one approved answer, served the same way to advocates and members. Every name, plan and figure is invented except where a source is cited.

Live: https://nikjain15.github.io/Knowledge/ (case-sensitive)

## Pages

1. Current state: `day.html?mode=today`
2. Solution architecture: `day.html?mode=approach`
3. How it works: `how1.html` to `how4.html`
4. Future state: `day.html?mode=new`
5. Prove it: `prove.html`

Deep dives: `product.html`, `author.html`, `review.html`, `owner.html`, `desk.html`, `chat.html`, `channels.html`, `drift.html`, `evals.html`, `journey.html`, `roadmap.html`, `tradeoff.html`, `prd.html` (the PRD, also rendered as Markdown in the private repo).

## Run locally

Double-click `start-demo.command`, or run `python3 -m http.server 8743` in this folder and open http://127.0.0.1:8743/.
